Plan : Spider Tribuna multi-cantons pour extraction décisions
Spider Scrapy avec Playwright pour extraire 13,000+ décisions de jurisprudence depuis 6 cantons utilisant Tribuna, avec support first-run complet et mises à jour incrémentales hebdomadaires. Architecture testable à chaque étape.

Étapes
Initialiser projet Scrapy avec tests de connexion basiques

Créer structure Scrapy : scrapy startproject tribuna_scraper . générant scrapy.cfg, settings.py, dossiers spiders/, items.py
Installer dépendances : pip install scrapy scrapy-playwright pytest dans venv
Configurer settings.py : activer PLAYWRIGHT, définir DOWNLOAD_DELAY = 1, USER_AGENT, désactiver ROBOTSTXT_OBEY
TEST 1 : Spider minimal test_connection.py qui charge https://publicationtc.fr.ch/ avec Playwright et vérifie présence titre → scrapy crawl test_connection
Définir modèle de données et parser la page de recherche

Créer items.py avec TribunaDecisionItem : champs publication_date, decision_date, pdf_url, pdf_id, dossier_number, court, canton
Spider tribuna_base.py : méthode start_requests() ouvrant page avec Playwright, parse_search_form() injectant "e" dans .suchfeldAlles input, cliquant .fa-search
Méthode parse_results_page() : localiser .GB2UA-DDDUB → 2e tbody → table .GB2UA-DDKIC, compter nombre de <tr> trouvés
TEST 2 : Exécuter spider, logger nombre de résultats trouvés page 1 → scrapy crawl tribuna_base -a canton=FR -L INFO | grep "Found"
Extraire données de chaque ligne de résultat

Dans parse_results_page() : itérer sur chaque <tr> de la table
Sous-parser extract_row_data(row) : extraire td[cellindex="0"] (dates avec regex \d{2}\.\d{2}\.\d{4}), td[cellindex="8"] (attribut onclick ou data-*)
Créer items Scrapy avec dates parsées, pdf_id = None temporairement
TEST 3 : Afficher 5 premiers items en JSON → scrapy crawl tribuna_base -a canton=FR -o test_output.json -s CLOSESPIDER_ITEMCOUNT=5
Intercepter requêtes GWT pour capturer URLs PDF

Créer middleware playwright_interceptor.py : hook page.on("response") filtrant /loadTable + méthode POST
Parser réponses JSON GWT : extraire champs partURL et dossiernummer depuis payload, stocker mapping dossier → partURL en cache spider
Modifier extract_row_data() : utiliser cache pour construire pdf_url = f"https://publicationtc.fr.ch/tribunavtplus/pdf/{partURL}.pdf" (URL à confirmer)
TEST 4 : Vérifier 3 PDF URLs construites sont accessibles → scrapy crawl tribuna_base -s CLOSESPIDER_ITEMCOUNT=3 puis curl manuel sur URLs loggées
Implémenter pagination automatique

Méthode check_next_page() : chercher bouton .fa-angle-right parent, vérifier si disabled ou classe inactive
Si bouton actif : cliquer avec Playwright page.click(), attendre chargement .GB2UA-DDKIC, rappeler parse_results_page() récursivement
Logger numéro page courante et total items extraits
TEST 5 : Limiter à 3 pages → scrapy crawl tribuna_base -s CLOSESPIDER_PAGECOUNT=3 -L DEBUG vérifier logs pagination
Ajouter filtre dates pour mode mise à jour

Argument spider --days : calculer min_date = today - timedelta(days=N)
Dans parse_results_page() : si publication_date < min_date, logger skip + stopper pagination (return sans next page)
Mode first-run : --days=0 ou absence argument = tout extraire
TEST 6 : scrapy crawl tribuna_base --days=7 vérifier seules décisions <7j extraites, pagination s'arrête correctement
Rendre spider multi-cantons paramétrable

Créer canton_configs.py : dict TRIBUNA_CANTONS avec FR, GR (URL, langue, nom)
Modifier tribuna_base.py : argument -a canton=XX, charger config depuis dict, adapter start_urls et custom_settings
